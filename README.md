
# NeuroStack

**Code. Train. Visualize. Deploy.**

NeuroStack is an interactive AI engineering
learning platform for beginners and advanced learners.

## Learning Paths

1. Python Programming
2. Mathematics for AI
3. Data Science
4. Machine Learning
5. Deep Learning
6. Generative AI
7. MLOps and Deployment

## Features

- Interactive coding labs
- Mathematical explanations
- Algorithm visualizations
- Implementations from scratch
- Automated exercises and tests
- Real-world datasets
- Complete AI/ML/DL projects
- Model deployment

## Tech Stack

- Frontend: Next.js and TypeScript
- Backend: FastAPI and Python
- ML: Scikit-learn
- DL: PyTorch
- Database: PostgreSQL
- Visualizations: Plotly and React
